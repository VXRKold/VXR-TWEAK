Performance basics

Start with reversible settings before trying unknown optimizer tools.

01 / WINDOWS

Update your drivers

Get graphics drivers from your GPU maker or PC manufacturer. Avoid random driver download sites.

02 / FORTNITE

Check video settings

Try Performance Mode, lower demanding graphics settings, and restart the game after major changes.

03 / SYSTEM

Close background apps

Close apps you don't need while playing. Keep security software enabled.

04 / TESTING

Measure your FPS

Compare the same map and settings before and after a change. Track average FPS and stutters, not just one peak number.

Safe setup checklist

  1. Create a restore point before changing Windows settings.
  2. Change one setting at a time so you can undo problems.
  3. Keep a note of the original setting and your FPS before each test.
  4. Restart and test in the same game mode for a fair comparison.

Download safety

Be careful with .BAT, .REG, and .EXE files.
They can change your PC. Don't run unknown files as administrator or disable Windows Defender to install a tweak. A clean antivirus scan is useful, but it cannot guarantee a file is safe.

This starter site does not include executable downloads. Add only files you've reviewed and can explain, with clear instructions and rollback steps.
